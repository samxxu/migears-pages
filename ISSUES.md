**P3-3** — `src/Compiler.php:32,1040-1053 vs :105-107`

- EN: The path root accepts reserved variables and superglobals in the read direction: `{{ this.x }}` compiles to `## $this["x"] ?? "" ##`, `{{ _GET.token }}` to `## $_GET["token"] ?? "" ##`, `{{ GLOBALS }}` to `## $GLOBALS ?? "" ##`. The write direction (`loopVariable()`) rejects exactly these names, so the two directions disagree. Escaping limits the impact to contract violation rather than XSS, and the behaviour is shared by all three front ends.
- 中文: 路径根在「读」的方向上允许保留变量与超全局：{{ this.x }} 编译成 ## $this["x"] ?? "" ##，{{ _GET.token }} 成 ## $_GET["token"] ?? "" ##，{{ GLOBALS }} 成 ## $GLOBALS ?? "" ##。而「写」的方向（loopVariable()）恰好拒绝这些名字，两个方向不一致。转义使影响限于契约违反而非 XSS，且三个前端共享该行为。
- Verification / 验证: reproduced / 已实证
