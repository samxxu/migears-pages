# P2-1 — A `hidden` field's `label` is mandatory but never emitted: …

## Finding / 问题

- EN: A `hidden` field's `label` is mandatory but never emitted: `requireString($n, "label")` runs unconditionally, while the render step only outputs a label when `$input !== "hidden"`. Compiling a hidden field without a label throws; adding `label("IGNORED")` compiles fine and the value is discarded with no warning — against the module's stated "drop nothing silently" contract.
- 中文: hidden 字段的 label 是必填却永不输出：requireString($n, "label") 无条件执行，而渲染步骤只在 $input !== "hidden" 时输出 label。不给 label 会抛错；给了 label("IGNORED") 则编译通过且值被丢弃、无任何提示——与本模块自述的「不静默丢弃」契约冲突。
- Where / 位置: `src/Compiler.php:722 vs :772-774`
- Verification / 验证: reproduced / 已实证
